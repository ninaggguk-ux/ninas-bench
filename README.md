# ninas-bench
Nina's Bench is a single-file web app that benchmarks local LLMs and quants — speed and quality in one place. Connect LM Studio or Ollama, tick models, run the suite: TTFT, gen tok/s, prompt tok/s, plus 1–5 quality scores from your rating or an auto judge. Head-to-head quants, editable tasks, warm-up passes, CSV/JSON export — local-first, no build
